Ahora si, la justificación del punto 7:

Como bien sabemos, para hacer aplicaciones en distintas plataformas, lo normal es que cada una te pida un codigo de una manera distinta.
Pero eso lleva mucho tiempo en caso de querer hacer que una funcione en varias plataformas a la vez, como puede ser en android y en iphone.
Por eso se usan cosas como Flutter el cual en un lenguaje Dart se encarga de traducir el codigo para los lenguajes necesarios, es decir,
tu escribes la lógica, los calculas y la interfaz una sola vez, y Flutter se encarga de traducirla para el dispositivo necesario.
